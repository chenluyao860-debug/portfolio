# Lysia Chen — Portfolio 陈璐瑶（Lysia Chen）的个人设计作品集，展示品牌联名、IP 插画、视觉设计与产品设计项目。 ## 浏览方式 网站为纯 HTML、CSS 与 JavaScript，无需构建步骤。首页支持 List 与 Gallery 两种作品浏览方式；每个项目有独立详情页，并可通过页尾导航查看前后项目。 ## 本地预览 在项目目录运行： ```sh python3 -m http.server 8080 ``` 然后访问 。 ## GitHub Pages 在仓库设置的 **Pages** 中，将发布来源设为 `main` 分支的根目录。发布完成后，GitHub 会提供网站地址。
